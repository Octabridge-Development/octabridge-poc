# Diagramas C4

## Contexto
El proyecto OctaBridge utiliza IBM Watson para clasificar leads y enviar notificaciones. Los diagramas C4 describen la arquitectura del sistema.

## Diagramas
1. **Contexto**: Muestra los actores principales y cómo interactúan con el sistema.
2. **Contenedores**: Describe los componentes principales (skills, flow principal, etc.).
3. **Componentes**: Detalla la implementación interna de cada skill.

## Ubicación
Los diagramas están almacenados en esta carpeta y deben actualizarse con cada cambio significativo en la arquitectura.
